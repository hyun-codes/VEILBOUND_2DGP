# VEILBOUND

현실과 그림자 세계를 전환하며 길을 연결하고 위험을 피하는 2D 퍼즐 플랫폼 게임이다. Python + pico2d로 개발하고 Tiled로 맵을 편집한다. 플레이어의 무기·공격 기능은 사용하지 않는다.

## 현재 상태와 실행

Stage 1의 이동·전환 학습 구간과 Stage 2의 가로등 퍼즐 방 하나를 연결했다. 현실에서 E로 가로등 위치를 바꾸면 그림자 계단/다리가 달라진다. 기본 실행에서는 Stage 1 현실 포털 다음에 Stage 2로 진행하고, Stage 2 현실 포털에서 원형 완료를 표시한다. Stage 2 전체·Stage 3~5와 사망 모션·소리는 아직 미완성이다. 사람의 난도·재미 평가는 별도로 남아 있다.

Windows의 Python 3.13.15, pico2d 1.5.1, PySDL2 0.9.17, pysdl2-dll 2.32.10에서 실행을 확인했다. 현재 환경에는 이미 설치되어 있었으며 새 환경은 다음과 같이 준비한다.

```powershell
cd D:\VEILBOUND_2DGP
python -m pip install -r requirements.txt
python main.py
```

A/D 또는 좌우 방향키로 이동하고 Space를 짧게 누르면 낮게, 길게 누르면 높게 점프한다. Shift는 현실/그림자를 전환하며 W/S는 미사용이다. Stage 2에서는 현실의 RAIL 조작점 근처 지면에서 E로 가로등 위치를 바꾼다. R은 완료 상태에서도 플레이어·입력·카메라·세계를 현실 시작 상태로 복구한다. 출구 안내는 항상 표시하고 F1은 시작점·플레이어 충돌체를 표시/숨기고 F3은 배경 일렁임·안개 이동을 켜고 끈다. F3 설정은 재시작 후에도 유지한다. Esc 또는 창 닫기는 종료한다. 포커스를 잃으면 갱신을 멈추고 이동 입력·점프 버퍼·누적 시간을 비운다. 카메라는 자동 추적하며 상하 방향키로 직접 움직이지 않는다.

```powershell
python main.py --stage 2
python main.py --world shadow
python main.py --check-map
python -m unittest discover -s tests -v
```

`--world shadow`는 시험용 시작 세계만 그림자로 선택한다. 이후에는 Shift로 전환할 수 있고 R·추락 복귀는 항상 현실 시작 상태로 돌아간다. 기본 실행은 현실에서 출발한다. `--check-map`은 창을 열지 않고 맵을 검사한다. 다른 폴더에서도 `python D:\VEILBOUND_2DGP\main.py`로 실행할 수 있다.

## 확인 범위

2026-11-06: 자동 검사 74개 통과. A/D와 방향키의 중복 입력·해제·반대 방향 입력과 포커스 복귀를 검사하고 실제 SDL의 A/D 누름·해제 변환도 확인했다. 지면 y=183 정렬, 타일 경계 이동, 옆면·천장·착지, 점프 유예 0.08초·입력 버퍼 0.10초와 공중 추가 점프 금지, 키 유지·포커스·재시작, 30/60 FPS의 동일 물리 입력 결과를 검사했다. 현실의 점프 시작 시점을 110가지로 바꾼 검사에서 다리 우회가 없었고, 현실 출발·그림자 전환·다리 통과·출구 클리어·재시작을 연결해 검사했다.

실제 800×600 pico2d 창의 SDL 이벤트 큐에 시험 입력을 넣어 달리기·점프·반전·추락 복귀·그림자 다리 통과·창 닫기를 확인했다. 캡처에서 원본 모션·발 위치와 카메라 이동을 시각 확인했다. 사람이 직접 조작한 플레이 테스트와 감각·가독성 평가는 아직이다. 실제 SDL 입력으로 Shift 전환, 두 Shift 키의 중복 방지, 발판 소멸·추락, 지형 내부 전환 거부, Stage 1 클리어·입력 정지와 R 재시작을 확인했다. 사망 모션·몬스터·다음 스테이지 진행은 미구현이다.

실제 창 검사를 재현하려면 다음 명령을 사용한다. 캡처는 지정 폴더에 BMP로 저장하며 일반 자동 검사에서는 창을 열지 않는다.

```powershell
python tests/native_movement_check.py --output "$env:TEMP\veilbound-movement-check"
python tests/native_stage1_check.py --output "$env:TEMP\veilbound-stage1-check"
python tests/native_effects_check.py --output "$env:TEMP\veilbound-effects-check"
python tests/native_stage2_check.py --from-stage1 --output "$env:TEMP\veilbound-stage2-check"
```

현재 시험 수치: 이동 64px/s, 점프 초기 속도 240px/s, 상승 중력 1000px/s²·낙하 중력 1600px/s², 충돌체 6×14px. 월드 좌표 기준이며 최종 조작감은 플레이 후 조정한다. 현실의 틈은 점프로 우회할 수 없고 그림자 전환으로 다리를 연결해야 한다.


점프 조정(2026-11-06): 버튼을 놓으면 남은 상승 속도를 제한하는 가변 높이 점프와 상승보다 강한 낙하 중력을 적용했다. 최대 높이는 약 26.8px, 짧은 입력은 유지 시간에 따라 약 7.4~15px다. 길게 누른 점프의 상승은 약 0.23초, 낙하는 약 0.20초이며 마리오 원본 수치의 복제가 아닌 시험값이다. 누름·해제가 같은 갱신 사이에 들어와도 낮은 점프를 유지하고, 공중에서 다시 눌러 상승 속도를 되살릴 수 없게 검사했다. 관련 근거는 [코드 안내](game/README.md)를 따른다. 실제 SDL 입력 검사도 통과했으며 최종 감각 평가는 직접 플레이로 남겨 둔다.


세계 전환은 위치·속도를 그대로 유지하고 표시·충돌을 같은 고정 갱신에서 반영한다. 두 Shift 키를 겹쳐 눌러도 논리적인 한 번의 누름으로 처리한다. 대상 고체 안에 몸체가 겹치면 현재 세계를 유지하고 이유를 안내한다. 거부된 입력은 자동 재시도하지 않는다. 밟던 그림자 다리를 없애면 낙하하며, 사라진 발판의 점프 유예로 다시 뛰지 못한다.

출구 포털은 현실에서만 작동한다. 그림자에서는 테두리와 EXIT OFF 표시만 보이고, 닿으면 Shift로 현실 복귀를 안내한다. 그림자 상태에서는 클리어되지 않는다. 완료 시 이동·점프·전환과 카메라 갱신을 멈추고 R 재시도·Esc 종료를 안내한다. 등록된 Stage 2 원형만 이어서 로드하며 Stage 3 경로를 추측하지 않는다. 직접 조작한 점프 감각·가독성·퍼즐 안내의 충분성은 별도 평가가 필요하다.


세계 전환 시각 연출(2026-11-06): 성공한 Shift 전환에 약 0.2초의 배경 물결·색 전환과 짧은 세계 이름 표시를 연결했다. 그림자에서는 청보라색 배경·가로등과 느린 배경 일렁임, 반대 방향의 안개 흐름을 유지한다. 지면·캐릭터·조작·충돌·HUD에는 물결을 적용하지 않는다. F3을 꺼도 세계별 색·가로등·텍스트는 남는다. 전환 거부에는 성공 연출을 재생하지 않는다.

자동 검사에서 30/60/120 FPS 조건의 연출 시간, 배경 반복의 화면 가장자리 빈틈, 지형과 캐릭터 좌표의 독립성, F3·재시작·포커스 처리를 확인했다. 실제 SDL 검사에서 가로등의 청보라색 변환·물결·F3 OFF/ON·재시작 시 설정 보존과 기존 Stage 1 클리어를 확인하고 캡처를 검사했다. 원본 PNG는 변경하지 않았으며 가로등 TSJ에 visualRole=lamp만 추가했다. 음원 파일은 assets/에서 확인되지 않아 소리 전환은 아직 연결하지 않았다. 가로등 위치를 조작해 그림자 지형을 바꾸는 퍼즐 원형은 Stage 2에 연결했다. 사람이 느끼는 효과 강도·피로도와 다른 PC에서의 성능 평가는 남아 있다.


현실 전용 포털(2026-11-06): 포털 에셋은 아직 없으므로 임시 사각형 테두리를 유지한다. 자동 검사 65개와 실제 SDL 입력에서 그림자 다리 통과 → 포털 비활성 확인 → 같은 자리에서 현실 복귀 → 클리어 → R 재시작을 확인했다. 실제 포털 이미지·활성 애니메이션은 이후 연결한다. Stage 1→2 이동은 가로등 원형 작업에서 연결했다.


Stage 2 원형(2026-11-06): 아래 조작점에서 계단 배치 선택 → 그림자 계단을 점프해 위층 공통 발판 진입 → 현실 복귀·위 조작점에서 다리 배치 선택 → 그림자 다리 통과 → 현실 포털 진입이 기본 흐름이다. 적·시간제한은 없고 초기 상태는 BRIDGE다. R·추락은 현재 Stage 2를 다시 시작하며 가로등 상태와 입력·카메라를 초기화한다. F3 효과 설정은 유지한다. 자세한 좌표·Tiled 편집·해법과 확인 범위는 [Stage 2 문서](maps/stage_02/README.md)에 있다. 이전 절의 Stage 2 미구현 기록은 해당 작업 시점의 상태다.
