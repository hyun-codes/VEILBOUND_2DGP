# Stage 9 회전 공방

일반 진행과 `python main.py --stage 9`는 [stage9_clockwork_chamber.tmj](stage9_clockwork_chamber.tmj)를 연다. 기존 저수조 맵은 보존되어 회귀 검사에 사용한다.

## 조작과 규칙

- 왼쪽 손잡이 근처에서 E를 누르면 조작 모드가 된다.
- A/D 또는 좌우 방향키를 한 번 누를 때마다 방이 반시계/시계 방향으로 90도 회전한다. 키를 계속 누른 것으로 여러 번 회전하지 않는다. 0.75초간 부드럽게 돌아간다.
- 조작 중에는 플레이어가 손잡이에 머물고 방 내부를 확인할 수 있다. E를 다시 누르면 일반 이동으로 돌아온다. R은 구슬·열쇠·방 방향·조작 모드를 모두 초기화한다.
- 내부 발판과 칸막이는 실제로 회전한다. 가로 발판은 세로 벽이 된다. 열쇠도 원래 지형에 붙은 채 이동한다.
- 방 안에 내려놓은 구슬도 회전한다. 회전 중 물리는 멈추고, 회전이 끝나 조작을 해제하면 구슬은 바뀐 지형 위에서 다시 떨어진다. 품은 구슬은 방 밖의 플레이어와 함께 머문다.
- 중력은 화면 아래쪽으로 유지한다. 회전이 끝난 방향의 충돌은 정수 좌표 AABB이며 중간 각도에는 물리 이동을 하지 않는다.
- 세 열쇠와 구슬의 출구 받침대 도킹이 필요하다. 90도 방향에서 출구 쪽으로 이어지는 발판이 연결된다. 이동·점프만으로는 구슬을 운반·도킹하거나 방 방향을 바꿀 수 없다.

## 에셋과 편집

손잡이와 철제 프레임은 PixelLab에서 새 PNG를 생성했다. `assets/props/rotating_chamber.json`에 최종 생성 ID와 원본 크기를 기록했다. 겹침 수정까지 총 체험 생성 5회를 사용했다. 코드로 프레임이나 손잡이 도형을 그리지 않는다. 내부 발판·열쇠·구슬은 기존 게임 에셋이다.

프레임 그림은 원본 160×160으로 넓히고 발판보다 뒤에 그린다. 손잡이는 캐릭터 머리 위로 분리 배치했다. 회전 발판끼리 교차했던 지점은 나눠 두며 네 정방향 모두 사각형 겹침이 없는지 검사한다. 기계 프레임과 발판 끝이 만나는 접합부에는 전경 발판을 우선 그려 가려짐을 피한다.

Tiled의 `RotatingPlatform` 사각형이 0도 방향의 원본 지형이다. `RoomPivot`의 중심과 `size`, `exitOrientation`을 확인할 수 있다. 열쇠의 `rotates=true`는 회전 지형에 붙는다는 뜻이다. `RoomCrank`는 방 밖의 고정 바닥 위에 둔다. 그림 레이어의 PNG 경로는 프로젝트 내부 상대경로다.

`tools/build_late_stages.py`의 `rotating_room()`은 초기 배치를 만든다. Tiled 수동 수정 후 생성기를 실행하면 해당 맵을 덮어쓰므로 주의한다.

## 검증과 제한

`tests/test_rotating_chamber.py`에서 네 번 회전 후 지형과 구슬 위치 복원, 회전 중 이동 정지, 키 길게 누르기, 초기화, 조작 해제 후 구슬 낙하, 출구 방향 조건을 검사한다. 전체 해답은 좌표 대입 없이 이동·점프·E·좌우 입력으로 재생한다.

확인된 해답은 기본 방향에서 두 열쇠 회수, 180도에서 남은 열쇠 회수, 90도에서 출구 접근과 구슬 도킹 순서다. 이것이 최단 해답이라는 증명과 초견 플레이 난이도 측정은 수행하지 않았다. 최소 15회 도전 목표는 검증 전이다.
