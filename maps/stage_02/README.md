# Stage 2: 뒤틀린 계단

상태: 제작 계획. 이 폴더에는 아직 TMJ 맵이 없다.

현실 전용 발판과 그림자 전용 발판을 비교하고 전환 위치·순서를 추론하는 스테이지다. Stage 1에서 이동·점프·전환을 검증한 뒤 실제 점프 가능 거리에 맞춰 제작한다. PPT의 예시 배치를 확정된 맵으로 간주하지 않는다.

맵을 제작할 때 이 폴더에 TMJ를 추가하고 `../tilesets/`의 외부 타일셋을 공유한다. 스테이지별 게임 코드를 이 폴더에 넣지 않는다. 요구사항과 수용 기준은 [PRD](../../PRD.md), 경로 규칙은 [맵 관리 안내](../README.md)를 따른다.
