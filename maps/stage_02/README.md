# Stage 2: 뒤틀린 계단 — 빛이 길을 지우는 퍼즐 원형

가로등 A가 계단/다리를 만들고, 추가한 가로등 B의 직접광이 다리 한 구간을 지운다. 두 그림자가 겹쳐 사라지는 규칙은 아니다. 실제 광학 투영 대신 Tiled의 사전 정의 영역을 사용한다. 적·시간제한·무기·새 이미지 없이 기존 도시 PNG·공유 TSJ만 재사용했다. Stage 2 전체가 아닌 퍼즐 방 하나이며 사람의 재미·난도 평가는 아직이다.

## 실행·조작

```powershell
python main.py --stage 2
python main.py --stage 2 --check-map
python tests/native_stage2_check.py --from-stage1 --output "$env:TEMP\veilbound-stage2-check"
```

A/D·방향키 이동, Space 점프, Shift 세계 전환, E 가까운 A/B 조작, R 현재 스테이지 재시작이다. E는 현실·착지·근접 조건이 모두 맞아야 작동하며 유지 입력으로 반복하지 않는다. 가까운 두 조작점의 반경은 겹치지 않는다. 여러 점이 겹치도록 편집하면 가장 가까운 점 하나만 선택한다.

A는 아래·위 두 조작점에서 같은 아래 가로등을 제어한다. B는 위층·가운데 섬에서 같은 위층 가로등을 원격 제어한다. A 표시는 청색, B와 빛 표시는 황색이며 B의 원본 따뜻한 램프 색은 그림자에서도 유지한다. 점선 광선은 B 본체에서 지워지는 구간까지 연결된다. LIGHT / NO PATH는 밟을 수 없는 영역이며, 현실의 청색 점선은 A가 BRIDGE일 때 빛이 닿지 않아 남을 그림자 길의 미리보기다. 색 이외에도 A/B·현재 상태·문구·지형의 유무로 구분한다. F3 OFF에도 이 정적인 표시는 유지한다.

## 배치와 상태

논리 480×240, 8px 타일 60×30, 800×600 창과 nearest-neighbor 정수 3배 추적 카메라다. 두 80px 틈과 안전한 조작 섬을 담기 위해 기존 320px 폭에서 확장했다. 좌표는 Tiled 좌상단 기준이다.

| 요소 | 좌표·표면 |
| --- | --- |
| 시작점 / 아래 공통 지면 | 발 (28,183) / x=0..104, y=183 |
| A 아래 조작점 | (80,183), 반경16 |
| A 계단 | x=112..128, y=167 / x=136..152, y=151 |
| 위층 공통 지면 | x=160..216, y=135 |
| A 위 조작점 / B 위 조작점 | (172,135), 반경8 / (204,135), 반경8 |
| 앞쪽 그림자 다리 | x=216..296, y=135 |
| 가운데 공통 섬 / B 조작점 | x=296..328, y=135 / (312,135), 반경10 |
| 뒤쪽 그림자 다리 | x=328..408, y=135 |
| 출구 공통 지면 / 현실 전용 포털 | x=408..480, y=135 / (432,111,16,24) |

| A | B | 그림자 계단 | 앞쪽 다리 | 뒤쪽 다리 |

| STAIRS | NEAR 또는 FAR | 있음 | 없음 | 없음 |

공통 섬·현실 지면·계단·배경·플레이어는 B의 빛으로 지우지 않는다. 초기값은 A=BRIDGE, B=NEAR다. R·추락 시 두 값과 플레이어·세계·카메라를 초기화하고 F3 설정만 유지한다. 두 가로등 상태는 세계 전환으로 초기화하지 않는다.

## 기본 해법과 복구

아래 A를 STAIRS로 변경 → 그림자 계단 점프 → 위층에서 현실 복귀·A를 BRIDGE로 변경 → 위층 B를 FAR로 변경 → 그림자 앞쪽 다리 통과 → 가운데 공통 섬에서 현실 복귀·B를 NEAR로 변경 → 그림자 뒤쪽 다리 통과 → 출구에서 현실 복귀다. Stage 1 포털에서도 이 방으로 이어진다. Stage 2 뒤에는 등록된 맵이 없으므로 완료 화면을 표시한다.

앞쪽에서 B를 NEAR로 고정하거나, 섬에서 B를 FAR로 고정하면 해당 80px 틈을 넘지 못한다. 현재 최대 점프 높이는 약26.8px다. 잘못 조작해도 두 B 조작점의 공통 바닥은 남아서 그 자리에서 되돌릴 수 있다. A를 STAIRS로 두면 다리가 없지만 위층 A/B 조작점은 유지되어 복구할 수 있다. 정답을 아는 자동 입력의 통과를 재미나 난도 검증으로 해석하지 않는다.

## Tiled 편집과 데이터 규칙

[stage2_lamp_room.tmj](stage2_lamp_room.tmj)의 Common / RealOnly / ShadowOnly / Objects를 유지한다. RealOnly는 빈 레이어다. ShadowOnly 아래 두 레이어는 모두 A의 STAIRS / BRIDGE이며 lampState=stairs / bridge를 사용한다. 과거의 Lamp B - bridge 이름은 A의 다리라는 뜻으로 수정했다. 에디터에서 ShadowOnly를 켜고 A 프리셋을 하나씩 표시해 확인한다.

BRIDGE 레이어에는 두 구간의 전체 타일이 저장된다. B에 의한 제외는 실행 시 적용하므로 Tiled는 완성된 한 조합의 화면이 아닌 원본 지형과 편집용 Beam 사각형을 보여준다. Objects의 Beam_near=(216,128,80,16), Beam_far=(328,128,80,16)가 제외 영역이며 8px 셀에 맞춘다. 해당 영역 안에 완전히 포함되는 lampState=bridge의 그림과 고체만 함께 제거한다. 임의로 셀 중간에 빛 경계를 두거나 자유 투영을 기대하지 않는다.

맵 속성 puzzleType=lightErasure, lampInitialState=bridge, lightInitialState=near를 사용한다. LampControl.lamp=A / B로 대상, radius로 조작 반경을 지정한다. LampRail.stairsX=68 / bridgeX=92는 Route lamp의 X, EraserRail.nearX=196 / farX=208은 Eraser lamp의 X다. 가로등 이미지 크기는 원본7×33 그대로다. Exit.destination=Complete는 등록된 다음 맵이 없는 현재 마지막 원형이다. 누락된 필수 오브젝트·B 본체·잘못된 상태/빛 사각형은 로딩 검사에서 오류로 보고한다.

지면 GID 2..6, 내부9..13·16..20와 collisionTop=7을 재사용한다. 배경은 기존 반복 이미지를 수평 반복한다. 이미지·TSJ는 프로젝트 내부 상대경로이며 원본 PNG·공유 TSJ를 변경하지 않았다.
