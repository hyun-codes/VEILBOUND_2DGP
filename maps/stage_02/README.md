# Stage 2: 뒤틀린 계단 — 가로등 퍼즐 원형

현재는 난도·재미를 확인할 퍼즐 방 하나다. 완성된 Stage 2 전체나 사람의 플레이 평가가 끝난 맵이 아니다. [stage2_lamp_room.tmj](stage2_lamp_room.tmj)를 Tiled에서 편집하고 공통 외부 TSJ·원본 도시 PNG를 그대로 사용한다. 새 이미지를 만들지 않았다.

## 실행과 규칙

루트에서 python main.py --stage 2로 바로 시작한다. 기본 python main.py는 Stage 1에서 시작해 현실 포털로 들어가면 이 방으로 진행한다. A/D 이동, Space 짧게/길게 점프, Shift 전환, E 가로등 조작, R 현재 스테이지 재시작이다. F3의 배경 효과 설정은 스테이지 이동·재시작 후에도 보존한다.

같은 가로등 레일을 아래와 위의 두 RAIL 조작점에서 제어한다. E는 현실에서 조작점 근처 지면에 서 있을 때만 작동한다. 가로등의 아래쪽 위치가 좌우로 24px 바뀌며, 그림자의 계단/다리 프리셋과 충돌도 함께 바뀐다. 연속으로 누르고 있어도 한 번만 조작하고, 포커스 상실·재시작 시 예약 입력을 비운다. 같은 스텝에는 세계 전환을 먼저 적용한 뒤 E를 처리한다.

초기 배치는 BRIDGE다. 재시작·추락 복귀 시 현재 Stage 2의 현실 시작점과 BRIDGE 배치로 돌아간다. 마지막 포털은 현실에서만 작동하고 Stage 3 파일은 아직 없다. 출구에서 STAGE 2 CLEAR를 표시한다. 적·시간제한은 없다.

## 배치와 해법

논리 320×240, 8×8 타일, 정수 3배 표시다. 좌표는 Tiled 좌상단 기준이다.

| 요소 | 좌표·용도 |
| --- | --- |
| 시작점 | 발 (28,183) |
| 아래 공통 지면 | x=0..104, 표면 y=183 |
| 아래 조작점 | (80,183), 수평 반경 16px, 발 높이 오차 6px |
| STAIRS | x=112..128 표면167, x=136..152 표면151 |
| 위층 공통 발판 | x=160..192, 표면135 |
| 위 조작점 | (176,135), 수평 반경 12px, 발 높이 오차 6px |
| BRIDGE | x=192..272, 표면135 |
| 출구 공통 지면 | x=272..320, 표면135 |
| 현실 전용 포털 | (288,111,16,24) |

아래에서 E로 STAIRS를 선택 → 그림자로 전환 → 두 계단과 위층 공통 발판으로 점프 → 현실 복귀 → 위 조작점에서 E로 BRIDGE 선택 → 그림자 다리 통과 → 현실 복귀·포털 진입이 기본 경로다.

처음부터 BRIDGE로 고정하면 위층의 48px 높이를 오를 수 없다. STAIRS에 고정하면 출구 앞 80px 틈을 넘지 못한다. 현재 최대 점프 높이는 약 26.8px이며 수평 이동·유예를 포함한 우회 검사도 수행했다. 연타 자체보다 두 배치의 용도와 조작 위치를 이해하도록 만든 원형이다. 정답 경로의 재미와 설명의 충분성은 사람의 평가가 필요하다.

## Tiled 편집

Common, RealOnly, ShadowOnly, Objects를 유지한다. RealOnly는 현재 빈 지형 레이어다. ShadowOnly 안의 Lamp A - stairs / Lamp B - bridge 타일 레이어에 world=shadow와 lampState=stairs / bridge를 둔다. 에디터에서 ShadowOnly를 켠 뒤 두 프리셋 중 하나씩 표시해 확인한다. 저장된 초기 미리보기는 BRIDGE다. 실행에서는 이 에디터 숨김 값과 별개로 현재 가로등 상태로 필터링한다.

Objects의 LampControl 두 점이 조작 위치·radius를 정의하고, LampRail 점의 stairsX=68 / bridgeX=92가 Route lamp 타일 오브젝트의 좌하단 X를 정한다. 맵 루트 stageNumber=2, lampInitialState=bridge를 사용한다. Exit.destination=Complete는 등록된 다음 맵이 없는 마지막 원형을 뜻한다. 실제 빛의 방향을 계산해 그림자를 생성하는 엔진은 아니다.

지면은 기존 GID 2..6, 내부는 9..13·16..20만 사용한다. 공유 TSJ의 collisionTop=7을 적용하여 각 윗면을 맞췄다. TMJ·이미지·TSJ 경로는 프로젝트 내부 상대경로이며 원본 PNG와 타일셋 이미지는 변경하지 않았다. 레이어 ID 13개와 오브젝트 ID 11개는 중복 없이 저장했다.

## 검증

2026-11-06: 자동 검사 74개 통과. E의 근접·현실·착지 조건과 반복 누름 방지, 프리셋 표시/충돌 동기화, 재시작·포커스 입력 초기화, 고정 배치의 우회 방지, 30/60 FPS에서 동일 입력 경로 결과 일치, Stage 1→2 로딩과 Stage 2 재시작을 검사했다.

실제 pico2d/SDL 입력으로 순간 이동 없이 계단 점프·위 조작점·다리·현실 포털을 통과하고 재시작했다. --from-stage1 통합 검사에서는 Stage 1 포털부터 Stage 2 원형 클리어까지 연결해 확인했다. 캡처에서 가로등 이동·프리셋·표면·조작 안내·완료 표시를 시각 검사했다. 설치된 Tiled CLI의 JSON 내보내기와 렌더링에 성공했다. GUI에서 직접 편집한 검사나 사람이 직접 조작한 감각·난도·재미 평가는 아직이다.
