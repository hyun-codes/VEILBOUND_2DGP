# Stage 1: 사라진 다리 — 맵 초안

Tiled에서 이 폴더의 [stage1_missing_bridge.tmj](stage1_missing_bridge.tmj)를 연다. 외부 타일셋은 [지면](../tilesets/outer_city.tsj)과 [건물·소품](../tilesets/outer_city_props.tsj)이다. TMJ와 TSJ의 이미지 참조는 프로젝트 내 `../../assets/Outer City/` 상대경로다. 원본 PNG는 수정하지 않았다.

2026-11-05 폴더 정리에서는 파일 위치와 참조 경로만 변경했고, 이후 별도 정렬 수정에서 `Common` 그룹의 오프셋을 `(51.75,96)`에서 `(0,0)`으로 되돌렸다. 지면·다리·시작점·출구가 아래에 적힌 공통 좌표 기준으로 정렬되었다. 3배 추적 카메라 등 게임 표시 요구사항은 [PRD](../../PRD.md)를 따른다. 이동·충돌·점프의 이후 구현 검증은 아래 2026-11-06 기록을 따른다.

## 편집과 세계 미리보기

- `Common`: 배경 이미지, 공통 지면 `Ground`, 원본 건물·소품 `SetDressing`, 하단 안개. 배경과 소품은 비고체 장식이다.
- `RealOnly`: 현실의 짧은 다리 잔해. 기본 표시.
- `ShadowOnly`: 중앙 다리 전체. 기본 숨김. 그림자 미리보기는 RealOnly를 숨기고 ShadowOnly를 표시한다. 두 레이어는 상호 배타적으로 사용한다. 기존 지면 타일에 Tiled의 레이어 색조만 적용했다.
- `Objects`: `PlayerStart` 점 (28,183), `Exit` 사각형 (288,159,16,24), `BridgeGap` 설계 영역 (120,183,80,57). 적 오브젝트는 없다. Objects와 SetDressing의 표시는 Tiled의 Show Object Names 옵션으로 줄일 수 있다.

좌표는 Tiled의 좌상단 원점, Y 아래 방향이다. 시작점은 발 위치다. 공통 지면은 x=0..120, 200..320이고, 현실 잔해는 x=120..128, 192..200이다. 현실의 빈 구간은 x=128..192 (64px). 그림자 다리는 x=120..200 전체를 잇는다. 지면의 실제 윗면 픽셀은 y=183이다. 현재 로더는 solid와 world를 고체·표시 선택에 사용한다. surfaceY와 BridgeGap 등 나머지 설계 속성이 자동으로 게임 규칙을 생성하지는 않는다.

## 해상도와 픽셀 비율

8×8px 타일, 40열×30행 = 논리 320×240px다. 초기 제작에서는 스크롤 없는 한 화면을 정수 2배로 640×480px에 표시하고 좌우 80px, 상하 60px 여백을 두도록 정했다. 이 과거 설정이 TMJ 메타데이터에 남아 있다. 현재 게임의 표시 요구사항은 PRD의 3배 확대 추적 카메라로 변경되었으며 현재 미리보기는 app.py의 3배·전체 창 설정을 사용하며 과거 표시 메타데이터는 읽지 않는다. 추적 카메라와 맵 설정을 데이터로 연결할 때 메타데이터를 동기화한다. 모든 원본 이미지는 맵에서 1:1 크기이며 원본 PNG와 맵 배치를 늘이지 않는다. 현재 pico2d 실행은 플레이어 추적·데드존·선행 시야·경계 제한을 사용한다.

### 지면 타일의 구조와 인덱스

원본에 격자 메타데이터는 없다. 픽셀 배치에서 확인한 8px 단위 중앙 5열×5행의 지면 구조에 따라 8×8px, 7열×8행, 56칸, margin=0, spacing=0으로 정의했다. 16px 타일로 임의 해석하지 않았다. 이미지 바깥쪽 투명 여백도 격자에 포함된다.

Tiled local ID는 0부터, 맵 GID는 firstgid=1을 더한다. `localID=row*7+column`, 소스 사각형 `(column*8,row*8,8,8)`이다.

| 용도 | local ID | 맵 GID | 픽셀 확인 |
|---|---|---|---|
| 윗면 | 1..5 | 2..6 | 각 칸 아래쪽 y=7의 8픽셀만 불투명 |
| 첫 내부 행 | 8..12 | 9..13 | 각 칸 64픽셀 전체 불투명 |
| 두 번째 내부 행 | 15..19 | 16..20 | 각 칸 64픽셀 전체 불투명 |

실제 맵은 위 15개 local ID만 사용한다. 상단 타일은 7px의 투명 공간을 갖기 때문에 그리드 행 y=176의 보행 윗면은 y=183이다. 가장자리 파편과 투명 칸을 내부 채우기에 쓰지 않았다. GID=0은 빈 칸이며, 소품 타일셋은 firstgid=57, local ID=0..6을 사용한다. 그림자 다리도 같은 원본 타일을 재사용한다.

## 검증

### 현재 정렬 수정 검증

2026-11-05 정렬 수정에서 실제 맵 데이터는 `Common.offsetx=0`, `Common.offsety=0` 두 값만 변경했다. 수정 전 Git 버전과 JSON을 비교해 타일 배열·오브젝트 좌표·하위 장식 오프셋·외부 타일셋·카메라 메타데이터가 유지되는 것을 확인했다.

- 원본 지면 타일의 알파를 검사해 윗면이 셀 내부 y=7임을 확인했다. 맵 22행의 실제 지면 윗면은 `176+7=183`이다.
- Common 지면과 현실 잔해·그림자 다리의 윗면은 모두 y=183이다.
- 현실의 표면은 x=0..128, x=192..320으로 중앙 64px가 비어 있다. 그림자 표면은 x=0..320으로 연속된다.
- 시작점 `(28,183)`은 왼쪽 공통 지면 위에 있고, 출구 `(288,159,16,24)`의 아래 경계는 오른쪽 공통 지면 y=183과 일치한다.
- 건물·가로등·벤치·난간의 바닥 기준점 y=183도 지면과 일치한다. 달과 배경의 의도된 하위 오프셋은 유지했다.
- 원본의 상대경로를 검사하고 설치된 Tiled CLI로 현실 맵과 그림자 임시 변형의 JSON 내보내기·이미지 렌더링에 성공했다. 두 렌더에서 지면·다리·시작점·출구 정렬을 시각 확인했다. 저장된 원본 맵은 현실 표시·그림자 숨김 상태다.

GUI 편집기를 다시 열어 확인하거나 실제 게임을 플레이한 것은 아니다. 타일의 정렬과 표시를 검증했으며, 충돌체와 점프 거리·출구 트리거는 게임 코드 구현 후 검사한다.

### 이전 검증 기록

2026-11-05 폴더 정리 검증: 새 위치의 TMJ·외부 TSJ 2개를 파싱해 상대경로 참조 15개(이미지 13개, 타일셋 2개)를 확인했다. 이동 전 Git 버전과 비교해 경로를 제외한 타일·오브젝트·속성·오프셋이 동일하고 원본 이미지 40개가 변경되지 않았음을 검사했다. 설치된 Tiled CLI의 내보내기·렌더링에는 성공했지만 그 당시에는 Common 오프셋에 의한 정렬 문제가 남아 있었다. 이 문제는 위의 별도 정렬 수정에서 해결했다.

아래 기록은 초기 제작 시점의 검증이다.

파일 검사 완료: JSON 파싱, 두 외부 타일셋, 상대 이미지 경로 13개 실존 여부와 프로젝트 내부 경로, 타일셋 PNG 치수 일치, 타일 레이어별 1200칸, GID 범위, 네 최상위 레이어, 시작·출구, 적 없음, 현실 단절과 그림자 연결을 확인했다.

편집기 확인 완료: 설치된 Tiled 1.12.2에서 실제 TMJ를 열었고 원본 배경·건물·지면·달·소품과 시작/출구 오브젝트 표시를 확인했다. RealOnly/ShadowOnly 표시를 교대로 전환해 끊어진 지면과 연결되는 다리를 직접 확인했다. 최종 편집기 상태도 파일과 같은 현실 표시/그림자 숨김으로 복구했다. 파일 로드 중 오류 대화상자나 누락 이미지 표시는 관찰되지 않았다. 별도 설치는 하지 않았다.

초기 제작 당시 미확인: 플레이어 이동·점프·낙하·충돌, 세계 전환 중 판정, 출구 트리거 및 밸런스. 이후 이동 기반 검증은 아래 기록을 따른다. `solid` 속성만으로 충돌이 자동 구현되는 것은 아니다. 윗면의 투명 7px는 이후 collisionTop 속성으로 충돌 설계에 반영했다. 초기 맵 제작에서는 게임 코드·게임 루프·PRD·Git 작업을 진행하지 않았으며, 이후 PRD와 Git 관리가 별도 작업으로 추가되었다.


### 이전 pico2d 맵 미리보기 검증

이후 실행 기능에서 원본 TMJ·TSJ·PNG를 변경하지 않고 실제 800×600 pico2d 창을 열었다. 현실과 그림자를 각각 5프레임 출력해 실제 SDL 렌더링을 캡처하고 정상 종료했다. 화면에서 현실의 단절과 그림자 다리, 건물·지면 정렬, 3배 확대를 확인했다. 그림자 확인은 오른쪽 경계 카메라 위치에서 수행했다. 실행 작업 폴더를 프로젝트 밖으로 바꿔도 상대경로 로딩에 성공했다.

실행은 루트에서 `python main.py`, 그림자는 `python main.py --world shadow`다. 방향키는 미리보기 카메라 이동, R은 카메라 복구, F1은 시작·출구 마커 표시, Esc는 종료다. 현재 조작은 플레이어 이동과 다르다. 실제 플레이·충돌·Shift 전환·출구 동작을 검증한 것은 아니다. 자세한 환경과 검사 범위는 [루트 README](../../README.md)를 따른다.


### 2026-11-06 이동 기반 검증

맵 타일 배열과 원본 PNG는 유지하고 공유 지면 TSJ의 surface 타일 5개에 collisionTop=7을 추가했다. solid=true 타일 레이어에서만 고체를 만들며 표면 y=183과 시작 발 위치를 맞췄다. 건물·배경·램프·벤치·BridgeGap 설계 영역은 충돌 대상이 아니다. 현재 지면은 사방 고체이며 단방향 발판은 없다. Tiled CLI 내보내기에 성공했다.

자동 검사에서 착지·타일 이음새·벽·천장·유예·버퍼·재시작을 확인했다. 현실 다리에서는 점프 시작 시점을 110가지로 바꿔도 우회할 수 없었다. 그림자로 고정한 실행에서는 다리를 걸어 출구 영역까지 통과했다. 실제 pico2d 창에도 SDL 시험 입력을 넣어 이동·점프·반전·추락 복귀와 카메라 이동을 확인하고 캡처를 검사했다. 사람이 직접 조작한 게임 감각·공정성 평가는 남아 있다.

현재 실행은 A/D 또는 좌우 방향키 이동, Space 점프, R 플레이어·카메라 복구, F1 시작/출구·충돌체 표시, Esc 종료다. Shift 전환·출구 트리거·사망 모션은 아직 없다. 그림자 이동 확인은 루트에서 python main.py --world shadow로 실행한다. 이전 절의 수동 카메라 조작은 이전 버전 기록이다.


### 2026-11-06 세계 전환·출구 연결

이후 Shift로 Common+RealOnly / Common+ShadowOnly 표시와 고체를 함께 전환하도록 연결했다. 공중 전환은 위치·속도를 보존하며 대상 고체 내부에 몸체가 겹치면 전환을 거부한다. 면 접촉은 허용하고, 사라진 발판의 착지·이탈 유예는 제거한다. 현실·그림자 어느 상태에서도 Exit와 몸체가 겹치면 Stage 1 단독 완료를 표시한다. R·추락 후에는 항상 현실에서 다시 시작한다. Stage 2 파일을 생성하거나 목적지 문자열을 임의의 경로로 읽지 않았다.

자동 검사 52개와 native_stage1_check.py의 실제 SDL 입력으로 현실 출발 → 그림자 전환 → 다리 소멸·추락 → 다리 내부 전환 거부 → 현실 복귀 → 그림자 다리 통과·클리어 → R 재시작을 확인했다. 실제 화면 캡처에서 전환 거부 사유·출구 안내·클리어 표시를 검사했다. 앞 절의 Shift·출구 미구현 문구는 해당 작업 시점의 기록이다. 원본 TMJ·TSJ·PNG는 이번 연결에서 변경하지 않았다. 사람이 직접 조작한 감각·퍼즐 설명의 충분성, 사망 모션·몬스터·다음 스테이지 진행은 아직 검증하지 않았다.


### 2026-11-06 세계 전환 시각 표시

기존 이미지 레이어는 배경 물결·색 전환에, Low fog는 안개 흐름에 연결했다. 공유 소품 TSJ의 램프 local ID=2에 visualRole=lamp를 추가해 원본 황색 조명을 실행 중 청보라색으로 표시한다. TMJ 타일 배열·오브젝트·원본 PNG는 변경하지 않았다. Tiled CLI로 외부 TSJ를 포함한 맵 내보내기에 성공했다.

실제 SDL 시험 입력에서 세계별 화면·가로등, 전환 표시, F3 OFF/ON과 재시작 후 설정 보존을 확인했다. 배경 효과와 무관하게 Stage 1의 전환·추락·거부·클리어 경로도 통과했다. 자동 검사는 65개이며 하늘 반복의 양쪽 화면 경계 빈틈과 물리 독립성도 확인했다. 소리 전환·가로등 위치 조작 퍼즐은 아직 없으며 효과 강도·편안함에 대한 사람의 평가는 남아 있다.


### 2026-11-06 현실 전용 포털

이후 사용자 지시로 Exit는 현실에서만 완료되는 포털로 변경했다. 그림자에서는 임시 테두리와 EXIT OFF만 표시하고, 접촉해도 완료되지 않는다. 오른쪽 공통 지면에서 현실로 복귀해야 진행할 수 있다. 포털 영역 안에서 현실로 돌아오면 즉시 완료된다. 포털 에셋·다음 스테이지 맵은 아직 없으며 원본 TMJ·PNG를 변경하지 않았다. 자동 검사 65개와 실제 SDL 입력·캡처로 그림자 비활성, 현실 복귀 후 클리어와 재시작을 확인했다. 앞 절의 두 세계 공통 출구는 이전 버전 기록이다.
