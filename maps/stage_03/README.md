# Stage 3: 위험한 골목

상태: 제작 계획. 이 폴더에는 아직 TMJ 맵이 없다.

현실에서 쥐의 순찰을 관찰하고, 그림자 진입과 회피 시점을 판단하는 스테이지다. 안전한 관찰 지점과 위험 구간을 구분하고 다음 착지점·동물 위치가 카메라에서 보이는지 확인한다. 실제 배치와 동물 수·속도는 아직 확정하지 않았다.

맵을 제작할 때 이 폴더에 TMJ를 추가하고 `../tilesets/`의 외부 타일셋을 공유한다. 순찰·변신 코드는 `game/`의 공통 구현을 사용한다. 요구사항과 수용 기준은 [PRD](../../PRD.md), 경로 규칙은 [맵 관리 안내](../README.md)를 따른다.
