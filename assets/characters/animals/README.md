# 현실 세계 동물 이동 에셋

2026-11-06 사용자 요청으로 쥐·고양이의 이동 시트를 새로 생성하고, 명시적으로 승인받은 Python 픽셀 후처리를 적용했다. 원본 Demonic SteamPunk 팩에 포함된 공식 동물 에셋이 아니다. 기존 캐릭터·맵 이미지는 수정하지 않았다.

| 종류 | 게임용 PNG | 실제 동물 크기 | 프레임 |
| --- | --- | --- | --- |
| 쥐 | [rat/rat_walk.png](rat/rat_walk.png) | 꼬리 포함 최대13×5px | 오른쪽 걷기6개 |
| 고양이 | [cat/cat_walk.png](cat/cat_walk.png) | 꼬리 포함16×9px | 오른쪽 걷기6개 |

두 시트 모두384×64px, 64×64 셀6개가 한 줄이며 투명 여백을 포함한다. 확대 저장한 게임용 이미지를 쓰지 않는다. 그림은 원본 플레이어(대기 몸체 약6×15px)와 비교해 작은 동물 크기로 맞췄다. 눈·흰 눈점·수염·털·발가락·장비·공격·사망 모션은 추가하지 않았다.

## 색상과 픽셀 정리

팔레트는 기존 Jack1.png의 회색 `(89,87,87)`, 밝은 회색 `(128,123,122)`, 갈색 `(79,52,47)`과 Outer_City_Tileset.png의 어두운 색 `(42,30,35)`만 사용한다. 최종 PNG 알파는0/255 두 값뿐이다. 생성 원본의 번짐·반투명 경계를 제거하고 작은 격자로 축소한 뒤 기존 네 색에 대응시켰다.

`generated/` 안에는 내장 image_gen의 고해상도 원본과 실제 프롬프트를 보존했다. 실행용은 그 폴더의 PNG가 아니라 각 종류 바로 아래의 `*_walk.png`다. [tools/prepare_animal_sprites.py](../../../tools/prepare_animal_sprites.py)가 원본 알파230 미만 제거 → 프레임 공통 범위·발 끝 정렬 → 면적 축소 → 셀 피복 알파96 미만 제외 → 팔레트 제한 →64px 셀 배치 순서로 재현한다. 이 도구는 오프라인 에셋 작업용 Pillow를 사용하며 게임 실행 의존성에는 추가하지 않았다. 이번 작업은 이미 설치된 번들 Python의 Pillow로 수행했다.

## 검증 범위

각6개 프레임의 비어 있지 않음·서로 다른 픽셀·같은 발 아래 경계44px, 원본 팔레트 사용·반투명 없음, PNG 크기·JSON 범위·경로·해시와 처리 재실행 결과의 일치를 검사했다. 원본 플레이어·도시 타일과 나란히 놓은 프레임 비교 이미지를 시각 확인했고,6프레임100ms 반복 GIF의 순서·시간·루프 설정을 검사했다. 미리보기는 비교용 합성 이미지이며 실제 pico2d 실행 화면이 아니다.

아직 Stage 3에 배치하거나 현실 동물→그림자 임프 변환·순찰·접촉 판정을 구현하지 않았다. 100ms는 초기 재생 시간으로 실제 이동 속도와의 동기화·게임에서의 루프 자연스러움·사람의 플레이 평가는 남아 있다. 고양이 행동을 먼저 추가하라는 뜻도 아니다.
