# 쥐 걷기 시트

- [rat_walk.png](rat_walk.png): 오른쪽으로 걷는6프레임,384×64px,64×64 셀6열×1행. 실제 동물은 꼬리 포함 최대13×5px다.
- [animations.json](animations.json): 프로젝트 자체 격자 메타데이터. walk만 등록했으며 공격·사망·대기는 없다.
- [generated/](generated/): AI 생성 원본과 프롬프트. 원본 팩에서 추출한 쥐가 아니라 생성 후 승인된 Python 픽셀 정리를 적용한 에셋이다.

셀 내부 발 기준점은 `(32,44)`, 기본 방향은 오른쪽이다. JSON의 row·columns는 좌상단0 기반이며 셀 좌표는 `(column*64,0,64,64)`, pico2d의 아래쪽 원점도 이 한 줄 시트에서는 동일하다. 왼쪽 이동은 향후 가로 반전으로 처리할 수 있지만 이번에는 게임 연결을 하지 않았다.

프레임당100ms·반복은 초기값이다. 여섯 프레임은 모두 서로 다르며 발 아래 경계는44px로 같다. 회색 몸·작은 귀·단순한 꼬리·작은 발로 구성했고 눈·흰 눈점·수염·세밀한 털을 넣지 않았다. 투명 알파0/255와 기존 팔레트 네 색으로 제한했다. [공통 처리·검증 기록](../README.md)을 따른다.

현재 game/player.py의 AnimationSet은 플레이어5개 모션을 요구하므로 이 JSON을 그대로 전달하지 않는다. 동물 구현 시 walk를 읽는 소비 코드가 필요하다. 충돌체·순찰 속도·새끼/성체 크기·그림자 임프와의 위치 대응은 아직 정하지 않았다.
