# 고양이 대기·걷기 시트

- [cat_walk.png](cat_walk.png): 오른쪽으로 걷는6프레임,384×64px,64×64 셀6열×1행. 실제 동물은 꼬리 포함16×9px다.
- [cat_idle.png](cat_idle.png): 걷기 시트 첫 자세의 몸과 발을 고정하고 꼬리만 바꾼 대기 3프레임. 192×64px, 64×64 셀.
- [animations.json](animations.json): Stage 4에서 재생하는 대기·걷기 메타데이터.
- [generated/](generated/): AI 생성 원본과 프롬프트. 원본 팩에서 추출한 고양이가 아니라 생성 후 승인된 Python 픽셀 정리를 적용한 에셋이다.

셀 내부 발 기준점은 `(32,44)`, 기본 방향은 오른쪽이다. JSON의 row·columns는 좌상단 0 기반이다. Stage 4에서는 진행 방향에 맞춰 좌우 반전한다.

프레임당100ms·반복은 초기값이다. 여섯 프레임은 모두 서로 다르며 발 아래 경계는44px로 같다. 삼각 귀·꼬리·단순한 다리와 작은 밝은 몸통 면만 사용했고 눈·흰 눈점·수염·세밀한 털·장비를 넣지 않았다. 투명 알파0/255와 기존 팔레트 네 색으로 제한했다. [공통 처리·검증 기록](../README.md)을 따른다.

현실에서는 양 끝에서 잠깐 멈추며 왕복하고, 그림자로 바꾸면 같은 위치에 지상 임프가 나타난다.
