# 지상 임프 에셋

Stage 3 이후 현실의 쥐·고양이에 대응할 그림자 세계 외형 후보다. 현재는 원본 시트와 애니메이션 메타데이터만 준비했으며 몬스터·세계별 외형 전환·접촉 위험·맵 배치는 구현하지 않았다. 쥐·고양이의 순찰 특성은 이후 별도 설정으로 관리하며 같은 임프 이미지 사용이 같은 행동을 뜻하지 않는다.

## 파일과 격자

- [Imp_spritesheet.png](Imp_spritesheet.png): 사용자 제공 원본. 외부 Demons/Imp 원본과 파일 바이트가 같음을 확인했으며 수정하지 않았다.
- [animations.json](animations.json): 프로젝트 자체 `veilbound-grid-animations` 버전1 메타데이터. Aseprite/Tiled 내보내기 형식이 아니다.
- 로컬 `Individual sprites/`는 원본 대조용이며 실행 필수 파일이 아니다. 개별 PNG를 실행 시 하나씩 읽도록 등록하지 않았다.

실제 PNG는 **832×320px**, 셀64×64px, **13열×5행**, margin/spacing=0이다. 플레이어나 비행 임프처럼10열이라고 가정하면 안 된다. JSON의 row·columns는 좌상단 원점의0 기반 인덱스다. 빈 셀까지 재생하지 않는다.

## 등록한 모션

| JSON 이름 | 행 인덱스 | 열 인덱스 | 프레임 수 | 대조한 개별 원본 | 반복 | 프레임당 초기 시간 |
| --- | --- | --- | --- | --- | --- | --- |
| idle | 0 | 0..6 | 7 | Imp animations1.png..7.png | 예 | 140ms |
| run | 2 | 0..7 | 8 | Imp animations10.png..17.png | 예 | 90ms |

이름은 확대 시각 검사로 추론했으며 제작자의 공식 모션 명세를 확인한 것은 아니다. 위15개 셀은 해당 개별 PNG와 RGBA 전체 픽셀이 일치한다. `Imp animations1.png`와4는 같은 그림이지만 원본 순서를 유지한다.

개별 폴더에 `Imp1.png` 계열과 `Imp animations1.png` 계열이 함께 있다. 특히 Imp10..17.png 등의 일부는 현재 시트 셀과 일치하지 않으므로 이름이 비슷하다는 이유로 교체하지 않는다. JSON의 source_frame_numbers는 **Imp animations 번호**이며 시트를 일렬로 센 인덱스가 아니다. 런타임에서 사용할 실제 위치는 row·columns다.

1번 행의2프레임은 전환·방향 변화 후보(정확한 명칭 미확인), 3번 행은 공격, 마지막4번 행은 사망으로 보여 사용에서 제외했다. 몬스터를 처치하지 않는 현재 방향에 따라 공격·사망 클립은 animations에 등록하지 않았고 원본 이미지에만 남겼다. 플레이어 사망 연출 제외를 뜻하지 않는다.

## 좌표·기준점·연결 주의

셀 좌상단은 `(column*64, row*64)`, 자르기 크기는64×64다. pico2d의 아래쪽 원점 자르기는 `(column*64, 320-(row+1)*64, 64, 64)`다. 예: idle 첫 셀 `(0,256,64,64)`, run 첫 셀 `(0,128,64,64)`.

공통 발 기준점은 셀 안의 `(32,41)`을 초기값으로 두었다. 선택 프레임의 알파 경계 아래쪽은40~41px이며 프레임마다 투명 여백을 잘라 크기를 바꾸지 않는다. 기본 방향은 확대 검사에서 오른쪽으로 판단했고 왼쪽은 이후 좌우 반전으로 처리할 수 있다. 충돌체 크기·최종 발 정렬·이동 속도는 아직 정하지 않았다. PNG를 확대 저장하지 않고 기존 카메라 정수 확대를 사용한다.

enabled=true는 앞으로 사용할 클립 후보라는 뜻이며 현재 게임에서 재생된다는 뜻이 아니다. 기존 game/player.py의 AnimationSet은 플레이어 전용5개 모션을 요구하므로 이 JSON을 그대로 넘기면 안 된다. 몬스터 구현 시 별도 소비 코드 또는 공통 로더를 연결해야 하며 이번에는 게임 코드를 수정하지 않았다.

## 확인과 미확인

2026-11-06: PNG 크기·투명 영역·64px 셀 배치, 원본 바이트 동일성, JSON 해시·경로·프레임 범위·비어 있지 않은 셀·개별 원본15프레임의 RGBA 일치와 확대 시각 검사를 확인했다. 원본 제작자의 FPS 명세는 없어 재생 시간은 시험값이다. 실제 pico2d 재생·루프 연결의 자연스러움·좌우 반전·충돌·세계 전환·Tiled 배치·사람의 플레이 검증은 아직이다.
