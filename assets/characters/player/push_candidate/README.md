# 캐릭터 밀기 모션 — AI 생성 후보

2026-11-06 사용자가 캐릭터의 가로등 밀기 모션 생성을 요청했다. 기존 Jack1~139의 분류표에는 밀기 동작이 없으므로 원본에서 추출한 프레임으로 가장하지 않는다. 이 요청에 한해 새 이미지 제작을 진행했으며 기존 원본 시트·개별 PNG·animations.json은 변경하지 않았다.

- `push_right_ai_draft.png`: 내장 image_gen으로 원본 Jack1·Jack18을 참고해 생성하고 한 번 수정한 오른쪽 밀기 후보. 1536×1024 RGBA, 512×512 셀의 3열×2행, 왼쪽부터 위→아래 여섯 프레임이다.
- `inspection.json`: 실제 이미지 크기·알파 통계·프레임별 강한 알파(240 이상) 경계 측정. 프레임 경계는 생성에 요청한 격자이며 게임 로더 등록 형식이 아니다.
- `PROMPT.md`: 최종 수정 요청 원문과 입력 파일 기록.

## 검수 결과와 사용 상태

무기 없이 오른쪽으로 팔을 뻗고 다리 자세가 바뀌는 여섯 포즈는 확인했다. 그러나 원본보다 모자·체형·실루엣이 달라졌고, 알파가 0/255가 아닌 반투명 번짐이 남는다. 원본64×64 셀·약15px 캐릭터와 같은 픽셀 격자·발 앵커를 보장하지 않는다. 512px 셀을64px로 축소해도 자동으로 원본과 일치한다고 판단할 수 없다. PNG에 투명 픽셀이 있다는 것과 깨끗한 투명 테두리는 별개다.

**게임 투입 가능한 최종 에셋이 아니다.** animations.json이나 Player에 등록하지 않았고 실제 밀기 모션 재생도 검증하지 않았다. 프레임당120ms는 검토용 제안일 뿐 원본 제작자 수치나 검증된 재생 시간이 아니다. 코드·의존성·가로등 조작 방식도 이 에셋 후보 작업에서는 변경하지 않았다.

실제 적용 전에는 원본 캐릭터의 외형과15px 크기에 맞춘 픽셀 보정, 반투명 경계 제거, 손 접점·발 기준점·루프 연결 검수와 게임 크기 재생 확인이 필요하다. 이 파일은 참고 또는 보정 출발점으로만 사용한다. 기존 모션을 대체하지 않는다.
