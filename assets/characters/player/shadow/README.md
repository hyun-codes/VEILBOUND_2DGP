# 그림자 세계 플레이어

VEILBOUND의 그림자 세계용 Jack 스프라이트 시트다. Jack의 가는 몸 위에 보라색 불꽃 머리를 얹었다. 대기 중에는 불꽃이 위로 솟고, 달릴 때는 진행 방향 뒤로 길게 흐른다.

- [shadow_jack_flame.png](shadow_jack_flame.png)는 현재 버전의 투명 RGBA PNG다. 512×320px에 64×64px 셀 8열×5행을 배치했다. [모자가 있는 첫 버전](shadow_jack.png)도 비교용으로 볼 수 있다.
- [animations.json](animations.json)은 기존 `AnimationSet`이 읽는 형식이다. 오른쪽을 바라보며 발 앵커 `(32,44)`와 모션별 프레임 재생 시간은 [현실 세계 설정](../animations.json)을 따른다.
- 위에서부터 대기 3컷, 달리기 8컷, 점프 시작 5컷, 낙하 4컷, 착지 4컷이다. 각 행은 첫 열부터 시작한다.

생성 시트에서 프레임을 추출해 최근접 샘플링으로 축소하고 원본 모션의 발 높이에 맞춰 배치했다. Shift 전환이 성공하면 해당 세계의 시트를 표시하고 현재 동작의 재생 시점을 이어간다. 현실로 돌아오거나 R로 재시작하면 기존 Jack 시트를 표시한다.

달리기 8컷의 목 아래는 원본 Jack15~22의 픽셀을 같은 위치에서 가져와 보라색 팔레트로 입혔다. 원본의 팔 스윙과 발 디딤을 유지하고 프레임마다 불꽃 머리를 정렬했다. 재생 속도는 80ms/컷이다.

내장 이미지 생성 도구에 《Dead Cells》 주인공의 불꽃 머리 실루엣을 참고해 모자와 얼굴을 없애고, 밝은 라일락 중심부와 짙은 보라색 끝을 가진 불꽃으로 머리 전체를 그리도록 요청했다. 빈손과 기존 24컷의 동작 순서, 투명 배경을 생성 조건으로 지정했다.
