# 그림자 세계 플레이어

VEILBOUND의 그림자 세계용 Jack 스프라이트 시트다. 원본 Jack의 짧은 모자와 가는 체형을 참고해 내장 이미지 생성 도구로 그렸다. 모자·등·팔·다리의 보라색 윤곽이 프레임마다 달라져 몸이 그림자 불꽃처럼 일렁인다.

- [shadow_jack.png](shadow_jack.png)는 투명 RGBA PNG다. 512×320px에 64×64px 셀 8열×5행을 배치했다.
- [animations.json](animations.json)은 기존 `AnimationSet`이 읽는 형식이다. 오른쪽을 바라보며 발 앵커 `(32,44)`와 모션별 프레임 재생 시간은 [현실 세계 설정](../animations.json)을 따른다.
- 위에서부터 대기 3컷, 달리기 8컷, 점프 시작 5컷, 낙하 4컷, 착지 4컷이다. 각 행은 첫 열부터 시작한다.

생성 시트에서 프레임을 추출해 최근접 샘플링으로 축소하고 원본 모션의 발 높이에 맞춰 배치했다. 어두운 보라 회색 배경에서 3배 크기의 프레임 가독성을 확인했다. 현재 상태는 에셋 및 애니메이션 데이터 검증이며 게임의 세계 전환 재생은 연결 전이다.

생성 지시는 원본 Jack의 무장하지 않은 다섯 동작과 오른쪽 실루엣을 참고하고, 모자·등·팔·다리의 짧은 그림자 불꽃이 프레임마다 달라지도록 하는 것이었다. 두 번째 생성에서는 포즈와 배치를 유지하며 몸통과 발에 밝은 보라색을 써서 어두운 배경과의 대비를 높이도록 했다.
