# Red Hand Jack 스프라이트 분류표

확인일: 2026-11-05. 이 문서는 사용자 제공 캐릭터 자료를 분류한 기록이며 애니메이션 구현 완료를 뜻하지 않는다. VEILBOUND는 두 세계 모두에서 무기·공격·사격을 사용하지 않는다.

## 확인한 원본과 방법

- 사용자 제공 `Player Character/Red_Hand_Jack_SPRITESHEET.png`
- 같은 폴더의 `Individual sprites/Jack1.png`부터 `Jack139.png`
- 같은 폴더의 `Info on the spritesheet.txt`

시트는 640×1664px이고 각 셀은 64×64px, 10열×26행이다. 개별 PNG 139개도 모두 64×64px다. 실제 그림이 있는 시트 셀을 위에서 아래, 왼쪽에서 오른쪽으로 읽으면 Jack1~135와 각각 RGBA 픽셀이 완전히 일치한다. Jack136~139는 알파가 전부 0인 투명 이미지다. 파일명 문자열순 정렬(Jack1, Jack10, Jack100…) 대신 숫자순으로 검사했다.

무기 유무는 개별 프레임을 확대해 확인했다. 설명서는 24개 모션을 나열하지만 실제 시트는 26행이므로 명칭을 순서대로 기계적으로 대응시키지 않았다. 특히 13행의 무장 공중 모션과 20행의 낫 소멸 동작을 구별했다. 이름이 불명확한 행은 동작 묘사와 추정 여부를 함께 기록한다. 재생 시간·FPS는 해당 설명서에 없어 확정하지 않았다.

## 3. 사망 모션: 무기 유무를 나눠 확인

사망 후보는 22행 **Jack117~121, 총 5프레임**이다. 원본 설명서의 death 표기와 실제 쓰러지는 모습을 함께 확인했다. 그러나 전체 모션은 무기 없는 전용 사망으로 바로 사용할 수 없다.

| 파일 | 실제 이미지 | 분류 |
| --- | --- | --- |
| Jack117 | 주황색 낫과 캐릭터가 함께 표시됨 | 사용 제외 |
| Jack118 | 낫이 흰색·주황색으로 소멸하는 형태가 남아 있음 | 사용 제외 |
| Jack119 | 몸이 낮아지고 위쪽에 흰 입자가 남음. 낫·총 형상은 보이지 않음 | 조건부 후보 |
| Jack120 | 캐릭터가 바닥에 쓰러져 있고 위쪽에 작은 흰 입자가 남음 | 조건부 후보 |
| Jack121 | 바닥에 누운 캐릭터, 낫·총 형상 없음 | 조건부 후보 |

Jack119~121만 고르면 무기 형상은 피할 수 있지만, 소멸 효과 후반부터 시작하고 중간 자세가 생략되어 연결이 갑작스러울 수 있다. Jack114~116의 무기 없는 피격 뒤에 연결하는 방법도 시험 후보일 뿐 확정 모션이 아니다. 전체 Jack117~121을 ‘death’라는 이름으로 자동 등록하지 않는다.

입자를 무기 효과의 일부로도 전혀 사용하지 않으려면 원본의 깨끗한 자세를 바탕으로 별도 모션을 준비하거나, 이후 허가된 에셋 편집에서 효과 제거를 검토한다. 이번 분류에서는 이미지를 수정하지 않았다. 사망 애니메이션은 여전히 재생 연결·프레임 속도·발 기준점 검증이 필요하다.
